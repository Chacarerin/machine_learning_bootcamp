El Aprendizaje Profundo (*Deep Learning*) representa la evolución natural de los modelos clásicos de Machine Learning. Este módulo tiene como objetivo académico comprender y aplicar arquitecturas basadas en Redes Neuronales Artificiales (ANNs), diseñadas para modelar patrones altamente no lineales en grandes volúmenes de datos, emulando conceptualmente el procesamiento sináptico humano.

## 📌 Contenidos Principales
- **El Perceptrón y Funciones de Activación:** Análisis matemático de las funciones (ReLU, Sigmoide, Tanh) que introducen la no-linealidad crítica en la red, permitiendo a los algoritmos aprender relaciones no triviales.
- **Propagación y Retropropagación (Backpropagation):** Estudio algorítmico del gradiente descendente y optimizadores estocásticos (Adam, RMSprop) para el ajuste dinámico de pesos sinápticos durante el entrenamiento continuo.
- **Regulación Estructural:** Implementación de arquitecturas Densas (MLP) y técnicas para prevenir el sobreajuste, como capas *Dropout* y mecanismos de parada temprana (*Early Stopping*).

## ⚙️ Tecnologías y Frameworks Aplicados
- **TensorFlow & Keras:** Se adopta *TensorFlow*, el estándar industrial desarrollado por Google para cálculo tensorial, integrado con su API de alto nivel *Keras*. Esta dupla permite abstraer la pesada carga matemática subyacente y enfocar el estudio en la topología, diseño y validación empírica de las redes neuronales.
