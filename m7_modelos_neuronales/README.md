# Módulo 7: Modelos Neuronales

Introducción al Deep Learning (Aprendizaje Profundo). Este módulo marca la transición de algoritmos tradicionales de Machine Learning a la construcción de Redes Neuronales Artificiales capaces de resolver problemas no lineales de alta complejidad.

## Contenidos Principales
- **Fundamentos Perceptrón:** Arquitectura básica, funciones de activación (ReLU, Sigmoid, Tanh) y funciones de pérdida.
- **Redes Neuronales Densas (MLP):** Propagación hacia adelante (Forward propagation) y hacia atrás (Backpropagation).
- **Entrenamiento y Optimización:** Uso de optimizadores estocásticos como Adam, RMSprop y SGD.
- **Prevención de Sobreajuste:** Capas de Dropout y Early Stopping.

## Aplicación Técnica
Implementación práctica utilizando Keras y TensorFlow, estructurando modelos secuenciales orientados a tareas de clasificación de imágenes y datos tabulares.
