# 📐 Módulo 3: Matemáticas para Machine Learning

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![NumPy](https://img.shields.io/badge/numpy-%23013243.svg?style=for-the-badge&logo=numpy&logoColor=white)

Este módulo sienta las bases teórico-prácticas fundamentales para el desarrollo matemático de algoritmos de Machine Learning. El enfoque principal recae en el análisis numérico, proveyendo al estudiante de las herramientas conceptuales necesarias para comprender el comportamiento de los datos y el funcionamiento interno de modelos predictivos avanzados, evitando tratar a los algoritmos como simples "cajas negras".

## 📌 Contenidos Principales
- **Álgebra Lineal Computacional:** Operaciones matriciales, vectores espaciales, y cálculo de determinantes. Estos conceptos son la piedra angular para el procesamiento de grandes volúmenes de datos n-dimensionales (Tensores).
- **Cálculo Diferencial Orientado a Optimización:** Uso de derivadas y el concepto de gradiente para encontrar los mínimos matemáticos en funciones de error.
- **Probabilidad y Estadística Aplicada:** Distribuciones de probabilidad, varianza, y fundamentos de la inferencia estadística para la validación rigurosa de hipótesis.

## ⚙️ Tecnologías y Frameworks Aplicados
- **NumPy:** Biblioteca fundamental para la computación científica en Python. Se utiliza aquí por su altísima eficiencia (escrita parcialmente en C) para ejecutar operaciones de álgebra lineal y transformaciones matriciales a gran escala, indispensables en ciencia de datos.
- **SciPy:** Módulo especializado que extiende las capacidades de NumPy, aportando herramientas de integración numérica y optimización matemática.
