# Módulo 9: Interpretabilidad y Explicabilidad

A medida que los modelos de Machine Learning (especialmente Deep Learning y ensambles) se vuelven más complejos, operan frecuentemente como "cajas negras". Este módulo se centra en las técnicas para abrir esa caja y entender *por qué* el modelo toma ciertas decisiones.

## Contenidos Principales
- **Importancia de la Explicabilidad:** Requisitos éticos, sesgos algorítmicos y confianza del usuario final.
- **Métodos Globales:** Feature Importance clásico en árboles de decisión y Permutation Importance.
- **Métodos Locales (XAI):** 
  - **LIME (Local Interpretable Model-Agnostic Explanations):** Explicación de predicciones individuales mediante aproximaciones lineales.
  - **SHAP (SHapley Additive exPlanations):** Basado en teoría de juegos para una distribución justa de la contribución de cada variable.

## Aplicación Técnica
Integración de librerías de interpretabilidad (shap, lime) en flujos de trabajo predictivos existentes para auditar resultados.
