# 🔍 Módulo 6: Modelos No Supervisados Avanzados

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Scikit-learn](https://img.shields.io/badge/scikit--learn-%23F7931E.svg?style=for-the-badge&logo=scikit-learn&logoColor=white)

A diferencia del aprendizaje supervisado, este submódulo introduce al estudiante en entornos donde la "verdad absoluta" (etiquetas objetivas) no está disponible. El propósito académico es desarrollar la capacidad analítica de extraer estructuras latentes, segmentar agrupaciones orgánicas y reducir la entropía en repositorios de datos masivos.

## 📌 Contenidos Principales
- **Segmentación de Instancias (Clustering):**
  - **K-Means:** Particionamiento espacial iterativo utilizando el método de minimización de inercia intra-clúster (Elbow Method).
  - **DBSCAN:** Agrupamiento basado en densidad, esencial para detectar configuraciones no esféricas y descubrir automáticamente instancias anómalas.
- **Reducción Ortogonal de Dimensionalidad:** Estudio teórico y práctico del **Análisis de Componentes Principales (PCA)** para la proyección de espacios n-dimensionales en ejes de máxima varianza retenida.
- **Representación Manifold:** Uso de T-SNE para visualizaciones en espacios de alta complejidad no lineal.

## ⚙️ Tecnologías y Frameworks Aplicados
- **Scikit-Learn:** Empleado por su sólida implementación matemática de los algoritmos K-Means y las transformaciones matriciales (SVD) necesarias para ejecutar PCA de manera computacionalmente eficiente sobre grandes volúmenes de datos.
