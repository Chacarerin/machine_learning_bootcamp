# Módulo 6: Modelos No Supervisados Avanzados

A diferencia del aprendizaje supervisado, este módulo se enfoca en el descubrimiento de patrones ocultos y estructuras latentes en conjuntos de datos no etiquetados.

## Contenidos Principales
- **Agrupamiento (Clustering):** 
  - K-Means y el método del codo (Elbow Method).
  - Algoritmos basados en densidad como DBSCAN.
  - Clustering Jerárquico.
- **Reducción de Dimensionalidad:** 
  - Análisis de Componentes Principales (PCA) para visualización y optimización computacional.
  - T-SNE para representaciones en baja dimensión de datos altamente complejos.
- **Evaluación No Supervisada:** Coeficiente de Silueta e índices de validación interna.

## Aplicación Técnica
Aplicación práctica en tareas de segmentación y análisis exploratorio profundo utilizando Scikit-Learn.
